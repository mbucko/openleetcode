# Combinations

You are given two integers ``n`` and ``k``. Return every way to choose ``k`` different numbers from ``1`` to ``n``. Write each combination in ascending order and list the combinations in ascending lexicographic order.
\
\
\
**Example 1:**

>**Input:** n = 4, k = 3\
>**Output:** [[1,2,3],[1,2,4],[1,3,4],[2,3,4]]

**Example 2:**

>**Input:** n = 3, k = 3\
>**Output:** [[1,2,3]]

**Example 3:**

>**Input:** n = 5, k = 1\
>**Output:** [[1],[2],[3],[4],[5]]

**Constraints:**

* ``1 <= n <= 20``
* ``1 <= k <= n``
