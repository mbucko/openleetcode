# Maximum Subarray

You are given an integer array ``nums``. Find the non-empty contiguous subarray with the biggest sum and return that sum.
\
\
\
**Example 1:**

>**Input:** nums = [-3,2,-1,5,-6,3,1]\
>**Output:** 6\
>**Explanation:** The subarray [2,-1,5] adds up to 6.

**Example 2:**

>**Input:** nums = [2]\
>**Output:** 2

**Example 3:**

>**Input:** nums = [3,1,-2,6,4]\
>**Output:** 12\
>**Explanation:** Taking the whole array gives 12.

**Constraints:**

* ``1 <= nums.length <= 10^5``
* ``-10^4 <= nums[i] <= 10^4``
