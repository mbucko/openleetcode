# Multiply Strings

You are given two non-negative integers ``num1`` and ``num2`` written as strings of digits. Return their product, also as a string of digits.

Don't convert the inputs to integers directly or use a big-integer library.
\
\
\
**Example 1:**

>**Input:** num1 = "12", num2 = "34"\
>**Output:** "408"

**Example 2:**

>**Input:** num1 = "999", num2 = "0"\
>**Output:** "0"

**Example 3:**

>**Input:** num1 = "25", num2 = "4"\
>**Output:** "100"

**Constraints:**

* ``1 <= num1.length, num2.length <= 200``
* ``num1`` and ``num2`` contain only digits.
* Neither number has leading zeros, except the number 0 itself.
