# Longest Palindromic Substring

You are given a string ``s``. Return the longest contiguous piece of ``s`` that reads the same forwards and backwards.

The test cases are chosen so that the longest such piece is unique.
\
\
\
**Example 1:**

>**Input:** s = "xyyz"\
>**Output:** "yy"

**Example 2:**

>**Input:** s = "q"\
>**Output:** "q"\
>**Explanation:** A single character is always a palindrome.

**Example 3:**

>**Input:** s = "cabad"\
>**Output:** "aba"

**Constraints:**

* ``1 <= s.length <= 1000``
* ``s`` contains only English letters and digits.
