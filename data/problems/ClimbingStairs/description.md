# Climbing Stairs

A staircase has ``n`` steps. With each move you go up either ``1`` or ``2`` steps.

Return how many different sequences of moves take you from the bottom to the top.
\
\
\
**Example 1:**

>**Input:** n = 4\
>**Output:** 5\
>**Explanation:** The five ways are 1+1+1+1, 1+1+2, 1+2+1, 2+1+1 and 2+2.

**Example 2:**

>**Input:** n = 6\
>**Output:** 13

**Constraints:**

* ``1 <= n <= 45``
