# Unique Paths

A robot starts at the top-left cell of an ``m x n`` grid and wants to reach the bottom-right cell. It can only move one cell right or one cell down at a time.

Return how many different paths it can take. Every answer fits in a 32-bit signed integer.
\
\
\
**Example 1:**

>**Input:** m = 2, n = 3\
>**Output:** 3\
>**Explanation:** The paths are RRD, RDR and DRR.

**Example 2:**

>**Input:** m = 4, n = 4\
>**Output:** 20

**Example 3:**

>**Input:** m = 1, n = 1\
>**Output:** 1

**Constraints:**

* ``1 <= m, n <= 100``
* The answer is at most ``2 * 10^9``.
