# Subsets

You are given an array ``nums`` of distinct integers. Return every subset of its values, including the empty one. Write each subset in ascending order and list the subsets in ascending lexicographic order. The empty subset comes first.
\
\
\
**Example 1:**

>**Input:** nums = [5,2]\
>**Output:** [[],[2],[2,5],[5]]

**Example 2:**

>**Input:** nums = [7]\
>**Output:** [[],[7]]

**Constraints:**

* ``1 <= nums.length <= 10``
* ``-10 <= nums[i] <= 10``
* All values in ``nums`` are distinct.
