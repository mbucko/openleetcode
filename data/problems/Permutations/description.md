# Permutations

You are given an array ``nums`` of distinct integers. Return every possible ordering (permutation) of its values, listed in ascending lexicographic order.
\
\
\
**Example 1:**

>**Input:** nums = [4,7,9]\
>**Output:** [[4,7,9],[4,9,7],[7,4,9],[7,9,4],[9,4,7],[9,7,4]]

**Example 2:**

>**Input:** nums = [5,-5]\
>**Output:** [[-5,5],[5,-5]]

**Example 3:**

>**Input:** nums = [8]\
>**Output:** [[8]]

**Constraints:**

* ``1 <= nums.length <= 6``
* ``-10 <= nums[i] <= 10``
* All values in ``nums`` are distinct.
