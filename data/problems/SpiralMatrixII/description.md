# Spiral Matrix II

Given a positive integer ``n``, build an ``n x n`` matrix filled with the numbers ``1`` to ``n^2`` in spiral order. Start at the top-left corner, go right along the top row, down the right column, left along the bottom row, up the left column, and continue inwards.
\
\
\
**Example 1:**

>**Input:** n = 3\
>**Output:** [[1,2,3],[8,9,4],[7,6,5]]

**Example 2:**

>**Input:** n = 1\
>**Output:** [[1]]

**Constraints:**

* ``1 <= n <= 20``
