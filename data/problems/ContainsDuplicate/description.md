# Contains Duplicate

You are given an integer array ``nums``. Return ``true`` if some value occurs more than once in it, and ``false`` if all of its values are different.
\
\
\
**Example 1:**

>**Input:** nums = [4,8,15,4]\
>**Output:** true\
>**Explanation:** The value 4 appears at index 0 and again at index 3.

**Example 2:**

>**Input:** nums = [5,6,7,8,9]\
>**Output:** false\
>**Explanation:** Every value appears only once.

**Example 3:**

>**Input:** nums = [2,2,9,9,9,5]\
>**Output:** true

**Constraints:**

* ``1 <= nums.length <= 10^5``
* ``-10^9 <= nums[i] <= 10^9``
