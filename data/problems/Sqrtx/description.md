# Sqrt(x)

You are given a non-negative integer ``x``. Return its square root rounded down to the nearest integer.

Don't use a built-in power or square-root function.
\
\
\
**Example 1:**

>**Input:** x = 16\
>**Output:** 4

**Example 2:**

>**Input:** x = 20\
>**Output:** 4\
>**Explanation:** The square root of 20 is 4.47..., which rounds down to 4.

**Example 3:**

>**Input:** x = 0\
>**Output:** 0

**Constraints:**

* ``0 <= x <= 2^31 - 1``
