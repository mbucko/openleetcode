# Largest Rectangle in Histogram

You are given an array ``heights`` of bar heights in a histogram, where each bar is one unit wide. Return the area of the largest rectangle that fits entirely inside the histogram.
\
\
\
**Example 1:**

>**Input:** heights = [3,1,4,4,2]\
>**Output:** 8\
>**Explanation:** The two bars of height 4 form a 4 x 2 rectangle with area 8.

**Example 2:**

>**Input:** heights = [6]\
>**Output:** 6

**Example 3:**

>**Input:** heights = [2,2,2]\
>**Output:** 6

**Constraints:**

* ``1 <= heights.length <= 10^5``
* ``0 <= heights[i] <= 10^4``
