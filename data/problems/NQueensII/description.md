# N-Queens II

Place ``n`` queens on an ``n x n`` chessboard so that no two attack each other: no two share a row, a column or a diagonal.

Return how many different placements there are.
\
\
\
**Example 1:**

>**Input:** n = 5\
>**Output:** 10

**Example 2:**

>**Input:** n = 2\
>**Output:** 0

**Constraints:**

* ``1 <= n <= 9``
