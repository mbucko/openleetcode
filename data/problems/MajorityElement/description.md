# Majority Element

You are given an array ``nums`` of length ``n``. Return the value that appears more than ``n / 2`` times (rounded down).

You can assume such a value always exists.
\
\
\
**Example 1:**

>**Input:** nums = [5,1,5]\
>**Output:** 5\
>**Explanation:** 5 appears twice, which is more than 3 / 2 = 1 time.

**Example 2:**

>**Input:** nums = [4,4,9,9,9,4,4]\
>**Output:** 4

**Constraints:**

* ``n == nums.length``
* ``1 <= n <= 5 * 10^4``
* ``-10^9 <= nums[i] <= 10^9``

**Follow up:** Can you do it in ``O(n)`` time and ``O(1)`` extra space?
