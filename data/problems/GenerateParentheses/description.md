# Generate Parentheses

Given ``n`` pairs of parentheses, return every string of ``n`` ``'('`` and ``n`` ``')'`` characters that is correctly balanced. List the strings in lexicographic order (``'('`` comes before ``')'``).
\
\
\
**Example 1:**

>**Input:** n = 2\
>**Output:** ["(())","()()"]

**Example 2:**

>**Input:** n = 1\
>**Output:** ["()"]

**Constraints:**

* ``1 <= n <= 8``
