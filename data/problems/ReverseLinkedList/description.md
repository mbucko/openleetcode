# Reverse Linked List

You are given the values of a singly linked list, from head to tail. Reverse the list and return its values, from the new head to the new tail.

The test runner passes the list as an array of values, so ``reverseList`` takes and returns an array.
\
\
\
**Example 1:**

>**Input:** head = [3,1,4,1,5]\
>**Output:** [5,1,4,1,3]

**Example 2:**

>**Input:** head = [8,9]\
>**Output:** [9,8]

**Example 3:**

>**Input:** head = []\
>**Output:** []\
>**Explanation:** An empty list stays empty.

**Constraints:**

* The list has between ``0`` and ``5000`` nodes.
* ``-5000 <= Node.val <= 5000``
