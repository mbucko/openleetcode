# Remove Duplicates from Sorted List

You are given a sorted linked list. Delete nodes so that every value appears only once, and return the resulting list, still sorted.

The test runner passes the linked list as an array of values from head to tail, and the result is returned the same way.
\
\
\
**Example 1:**

>**Input:** head = [2,2,5]\
>**Output:** [2,5]

**Example 2:**

>**Input:** head = [1,3,3,3,4,4]\
>**Output:** [1,3,4]

**Example 3:**

>**Input:** head = []\
>**Output:** []

**Constraints:**

* The list has between ``0`` and ``300`` nodes.
* ``-100 <= Node.val <= 100``
* The list is sorted in ascending order.
