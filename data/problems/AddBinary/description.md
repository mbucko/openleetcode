# Add Binary

You are given two binary strings ``a`` and ``b``. Return their sum, also as a binary string.
\
\
\
**Example 1:**

>**Input:** a = "101", b = "11"\
>**Output:** "1000"\
>**Explanation:** 5 + 3 = 8, which is 1000 in binary.

**Example 2:**

>**Input:** a = "0", b = "0"\
>**Output:** "0"

**Example 3:**

>**Input:** a = "1111", b = "1"\
>**Output:** "10000"

**Constraints:**

* ``1 <= a.length, b.length <= 10^4``
* ``a`` and ``b`` contain only ``'0'`` and ``'1'``.
* Neither string has leading zeros, except the string ``"0"`` itself.
