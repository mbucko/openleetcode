# Sort Colors

You are given an array ``nums`` where every value is ``0``, ``1`` or ``2``, standing for the colours red, white and blue. Sort it **in place** so all the 0s come first, then the 1s, then the 2s, and return it.

Don't use a library sort.
\
\
\
**Example 1:**

>**Input:** nums = [1,2,0,1,0,2]\
>**Output:** [0,0,1,1,2,2]

**Example 2:**

>**Input:** nums = [2,1]\
>**Output:** [1,2]

**Example 3:**

>**Input:** nums = [0]\
>**Output:** [0]

**Constraints:**

* ``1 <= nums.length <= 300``
* ``nums[i]`` is ``0``, ``1`` or ``2``.

**Follow up:** Can you do it in a single pass using only constant extra space?
