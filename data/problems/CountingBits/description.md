# Counting Bits

You are given a non-negative integer ``n``. Return an array ``ans`` with ``n + 1`` entries, where ``ans[i]`` is the number of ``1`` bits in the binary form of ``i``.
\
\
\
**Example 1:**

>**Input:** n = 3\
>**Output:** [0,1,1,2]\
>**Explanation:**\
>0 --> 0\
>1 --> 1\
>2 --> 10\
>3 --> 11

**Example 2:**

>**Input:** n = 6\
>**Output:** [0,1,1,2,1,2,2]\
>**Explanation:** 4 is 100, 5 is 101 and 6 is 110.

**Constraints:**

* ``0 <= n <= 10^5``
