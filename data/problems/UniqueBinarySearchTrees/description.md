# Unique Binary Search Trees

You are given an integer ``n``. Return how many structurally different binary search trees store exactly the values ``1`` to ``n``.
\
\
\
**Example 1:**

>**Input:** n = 4\
>**Output:** 14

**Example 2:**

>**Input:** n = 2\
>**Output:** 2

**Constraints:**

* ``1 <= n <= 19``
