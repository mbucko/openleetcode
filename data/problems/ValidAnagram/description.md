# Valid Anagram

You are given two strings ``s`` and ``t``. Return ``true`` if ``t`` can be formed by rearranging the letters of ``s``, using each letter exactly as many times as it appears in ``s``. Otherwise return ``false``.
\
\
\
**Example 1:**

>**Input:** s = "listen", t = "silent"\
>**Output:** true

**Example 2:**

>**Input:** s = "cat", t = "cut"\
>**Output:** false\
>**Explanation:** t has a "u" where s has an "a".

**Constraints:**

* ``1 <= s.length, t.length <= 5 * 10^4``
* ``s`` and ``t`` contain only lowercase English letters.
