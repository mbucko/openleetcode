# Find the Index of the First Occurrence in a String

You are given two strings ``haystack`` and ``needle``. Return the index of the first place where ``needle`` appears in ``haystack``, or ``-1`` if it doesn't appear at all.
\
\
\
**Example 1:**

>**Input:** haystack = "abcabcd", needle = "abcd"\
>**Output:** 3\
>**Explanation:** "abcd" starts at index 3.

**Example 2:**

>**Input:** haystack = "rainbow", needle = "bow"\
>**Output:** 4

**Example 3:**

>**Input:** haystack = "kitten", needle = "dog"\
>**Output:** -1

**Constraints:**

* ``1 <= haystack.length, needle.length <= 10^4``
* ``haystack`` and ``needle`` contain only lowercase English letters.
